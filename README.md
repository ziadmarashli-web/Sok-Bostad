# Sök bostad – Västra Götaland

En enkel, flerspråkig webbapp för att hitta och följa hyresvärdar i Västra Götaland.

## Publicering

`index.html` är startsidan och kan publiceras direkt med GitHub Pages.

## Underhåll

Hyresvärdar och länkar underhålls i `bolag.json`. Se `GUIDE-uppdatera-lankar.md`.

## Viktigt

Appen är ett stödverktyg och ersätter inte hyresvärdarnas egna webbplatser. Användaren registrerar sig alltid på respektive hyresvärds officiella webbplats.
